# Floosy · فلوسي

A personal money tracker in a single HTML file — bilingual (English / العربية), light and dark mode, charts and small analytics.

- Wallets (bank / cash / savings) with easy switching
- Transactions: spent, earned, transfer — with icon categories
- Dashboard: spending breakdown, income vs spending, balance trend
- Reports by period; copy as text or CSV; print
- Hide amounts, backup & restore, customizable dashboard

All data stays in your own browser (localStorage). Nothing is sent anywhere.

Open `index.html`, or enable GitHub Pages: Settings → Pages → Deploy from branch → `main` / root.
